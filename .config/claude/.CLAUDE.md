# Claude Code Configuration

## Memory

When saving memories or context to files, write in English regardless of the conversation language.

## Verification

Confirm an option is supported in the *target* context (ecosystem, runtime, plan tier), not merely documented somewhere.
A citation (help tag, URL) asserts you read it: never attach a source to a claim from recall.
A zero-result search is evidence about the query, not about the world: broaden the query or enumerate the space before asserting that something does not exist.

Validate a proxy before trusting an aggregate built on it: open one row the query matched and confirm it is the thing being counted.
A merely plausible query returns a plausible number, and the total never reveals what it summed.

## Environment

Nix manages this machine.
Install tools by adding them to the flake or Home Manager config, never with `npm -g` / `pip` / `cargo install`.

## Design principles

Prefer simplicity over pathological correctness.
YAGNI, KISS, DRY.
Avoid backward-compat shims or fallback paths unless they add no branching.

## Bulk edits

When a script changes many files or lines, state the invariant first and check it before reporting — the number changed equals the number targeted, and the result still parses.
Skipped items and a corrupted subset both exit zero.

## Editing

Don't delete pre-existing dead code.
Mention it instead.

Write a comment only when it carries what the code cannot: a constraint from outside this file, a non-obvious reason a choice was made, or a trap the next reader will otherwise hit.
Before adding one, ask what a reader who already has the code in front of them still doesn't know.
If the answer is nothing, don't write it.

Never narrate a change.
"Moved from X", "used to be Y", "replaces Z" belong in the commit message, not the file.
Never restate what the line below already says, and don't duplicate a commit body into a comment — the copy in the file is the one that goes stale.

When a comment must explain a choice, give the reason that stays true rather than the circumstance that will rot.
Match the comment density of the surrounding code.
