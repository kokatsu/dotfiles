# Claude Code Configuration

## Memory

When saving memories or context to files, write in English regardless of the
conversation language.

## Answering vs. acting

A question asks for an answer, not for changes. When the ask doesn't imply an
edit, answer it and say what you would change.

## Verification

Ground factual claims in a source checked this session — docs, tool output, the
code, git history, the live system — not recall. Confirm an option is supported
in the *target* context (ecosystem, runtime, plan tier), not merely documented
somewhere. If verification is impractical, say so and label the claim unverified.

## Environment

Nix manages this machine. Install tools by adding them to the flake or Home
Manager config, never with `npm -g` / `pip` / `cargo install`.

## Design principles

Prefer simplicity over pathological correctness. YAGNI, KISS, DRY. Avoid
backward-compat shims or fallback paths unless they add no branching.

## Editing

Don't delete pre-existing dead code. Mention it instead.
